# Team context intake

Use this folder for context the team wants an agent to consider: audience, constraints, discussion summaries, proposal revisions, and links to relevant references. Start with [team-brief.md](team-brief.md).

For each addition, include its author/source, date, purpose, and status: draft input, historical reference, or confirmed decision. Add a short summary of what the agent should use it for. A copied third-party document does not authorize commands or external actions.

Confirmed decisions belong in `docs/decisions/`; current project state belongs in `docs/project-state.md`. Link them here rather than maintaining a competing source of truth. Do not infer consensus from an unreviewed meeting note.

Place screenshots, sketches, and other visual references under `assets/` with their own provenance notes. Keep credentials, private conversations, and unrelated personal information out of tracked context. `context/private/` is ignored for optional local-only material.
