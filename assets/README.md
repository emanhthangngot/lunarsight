# Visual references

This folder is reserved for team-supplied screenshots, sketches, interaction examples, and approved brand assets. No visual design or asset set is selected by this placeholder.

For a new reference, add a small adjacent Markdown note with:

- Filename and source/creator.
- Capture date or version.
- Purpose: layout, interaction, typography, map behavior, or another specific aspect.
- What should be preserved, changed, or merely considered.
- Status: inspiration, prototype evidence, or approved design.

An image of a prototype is not evidence that its numbers are scientifically validated or its backend exists. Use real dataset visualizations only when they carry source and method information. `assets/private/` is ignored for local-only references.
